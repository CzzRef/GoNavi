## Summary

Follow-up after #1134: compact display for provider connection fields, layout hint control, single-option API format, model-management popup, CLI catalog cache, and catalog drag-reorder.

Does **not** change stored URL / API key / apiFormat values. Compact text is display-only.

## User-visible behavior

- Inline layout: URL drops `https://` / `http://`; format and key use head/tail ellipsis; three fields share a row from ~520px editor width.
- Layout ⓘ: description on top, segmented 并排/纵向 buttons, `?` on the right.
- Single API-format option renders a read-only input, not a Select.
- Model popup no longer has a “select default” tab; row feedback is a 1.6s popover.
- CLI model catalog is cached per `apiFormat`; refresh only when clicking `n/m 已启用`.
- Catalog grid and hidden list are drag-sortable (`presetOrder` in `layout.v1`). Connected chips are **not** reordered in this PR.
